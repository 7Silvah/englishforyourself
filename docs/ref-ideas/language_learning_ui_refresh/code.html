04

Estados de Corrección & Feedback Didáctico

Lógica adaptativa de refuerzo
check_circle
¡Correcto! Syntax Verified

Con he / she / it el verbo en presente simple siempre añade sufijo -s o -es.

Tip pedagógico: "She loves, he works, it runs."
Token: state-success +10 XP
error_outline
Casi: revisa la ortografía Orthography Alert

Escribiste travled en vez de la grafía estándar traveled (US) o travelled (UK).

Tip: La regla de doblar la consonante final aplica en sílabas acentuadas.
Token: state-warning +5 XP
cancel
Incorrecto Grammar Fault

Después de didn't el verbo debe permanecer en forma base infinitiva: go, no "went".

Regla canónica: "Did / Didn't" ya expresan el pasado en la cláusula.
Token: state-error 0 XP
